# ICMA151 – Statistics for Science I

I took this course on my second trimester at MUIC; initially, I wanted to take it during the summer break, but the course got canceled for some reason. The course is about basic statistics, just a bit more from what you learnt from Thai highschool.

## Course Snapshot

- **Tooling:** *R programming language* is used as main calculator for every tests.
- **Teaching style:** The lecturer, Prof.Chatchawan, speaks slowly and clearly.
- **Attendance rumor:** There's no attendance for my class, but some senior said there was, so do count your sick days.

## Personal Notes

- From my experience, this course is more about R functions than statistic concepts it self.
- Prof.Chatchawan does teach concepts a lot in class, but the quiz is heavy on computation side -- so you can just memorize how to use the R commands and pass the test.
- Admidtedly, didn't finish quiz 2 material, there's a lot of work back then and I don't have enough time, so I just write it down on the cheat sheet and use the remaining time learning how to use those commands.
- But, overall, I really like this course: I went back and try to understand every concepts before the final, and I could see these statistical tool's usefulness almost instantly on my personal projects.
